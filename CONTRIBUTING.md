# Contributing to Resolve AI

Thank you for contributing to Resolve AI and the IBM Db2 TechX Workshop!

## Guidelines
1. **Zero Secrets Policy**: Never commit credentials, passwords, or private API keys. Use `.env.example`.
2. **Quality & Tests**: Run `python3 scripts/validate_submission.py submissions/resolve-ai` and `npm run build` before opening a pull request.
3. **Pull Request Format**: Follow the template in `.github/PULL_REQUEST_TEMPLATE.md`.
